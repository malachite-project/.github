# malachite-project

Unofficial LineageOS 23.2 (Android 16) for the Redmi Note 14 Pro 5G / POCO X7 5G
(malachite).

**Downloads, updates and support:** [Telegram group](https://t.me/malachite_project)

## Repositories

Every repository has one branch, `lineage-23.2`. To build, or to base another ROM on
these trees, start from the
[device tree](https://github.com/malachite-project/android_device_xiaomi_malachite):
its `manifests/malachite.xml` lists every project and what each fork changes.
